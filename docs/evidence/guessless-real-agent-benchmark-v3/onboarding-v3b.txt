Guessless is a deterministic, fail-closed JavaScript/TypeScript structural-analysis tool available in this session. Use it when references, bindings, reachability, or rename/delete impact could help you implement or verify this maintenance change. Prepare the current worktree with guessless_prepare_snapshot using {"rootUri":"file://<absolute-current-worktree>"}; use the returned snapshot with guessless_safe_change_impact, or use narrower structural queries when appropriate. A receipt may be complete, partial with named unresolved sites, or refused; never treat omitted or unresolved sites as safe. Use is optional—decide whether it helps this task, and do not claim success merely because you invoked it.
