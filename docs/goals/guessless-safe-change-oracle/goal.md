## Goal Oracle

The oracle for this goal is:

`A final preregistered evaluation demonstrates >=99% completed Guessless calls, >=80% unforced correct selection, <=2 cold and <=1 warm semantic calls, zero added false completeness, no task regression, >=4 net paired correctness wins with one-sided exact p<=0.10, and either >=20% lower total workflow time or >=25% fewer total tool calls; preparation also reduces setup bytes >=80%, progressive output reduces initial bytes >=50% and downstream tokens >=25% without added calls or quality loss, and the full repository gates pass.`

The PM must keep comparing task receipts to this oracle. Planning, infrastructure alone, one passing unit test, or a cleaner MCP surface is not enough. The goal finishes only when a final Judge maps current implementation and evaluation evidence to every oracle clause and records `full_outcome_complete: true`.
