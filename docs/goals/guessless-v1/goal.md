## Non-Negotiable Constraints

- Treat the repository-root `goal.md` as the product specification and preserve its full scope.
- Copy the applicable Versionless structure: TypeScript, Vite Plus, pnpm workspace/monorepo conventions, package boundaries, repository scripts, and verification posture.
- Implement the engine before the MCP server and the CLI.
- Every answer is `complete`, `partial` with every unresolved site named, or `refused`; a bare list never ships.
- Identify constructs by definition origin, not spelling, and use symbol-anchored citations rather than line ordinals.
- JavaScript, TypeScript, JSX, and TSX via Yuku are the only v1 language scope.
- No embeddings, editing, lint-rule product, second parser/language, hosted service, auth, or persistence layer.
- Pin real fixtures by commit and record licenses; make external/network phases explicit.
- Mutation-prove every guard by observing it fail and restoring it byte-identically.
- Negative results and unmet oracle parts remain explicit deliverables.
- Maintain a root `AGENTS.md` that directs agents to prefer `magic-regexp` for regular expressions, UnJS `pathe` for filesystem path handling, and `ufo` for URL handling.
